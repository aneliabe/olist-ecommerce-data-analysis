# Case Olist

O conjunto de dados analisado pertence à Olist, maior loja de departamentos em marketplaces brasileiros. A Olist é um e-commerce que conecta pequenos negócios de todo o Brasil a canais de distribuição de forma descomplicada e com um único contrato. Os comerciantes podem vender seus produtos pela Loja Olist e enviá-los diretamente aos clientes utilizando os parceiros logísticos da Olist.

O conjunto reúne informações de aproximadamente 100 mil pedidos realizados entre setembro de 2016 e outubro de 2018, abrangendo dados sobre vendas, pagamentos, entregas, clientes, produtos e avaliações de satisfação.

Fonte dos dados: [Olist]([https://www.example.com](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce/data))
